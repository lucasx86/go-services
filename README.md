# GO Services! 📍🛠️

**Aplicativo mobile em planejamento** para conectar clientes a profissionais próximos, como eletricistas, mecânicos, encanadores e profissionais de limpeza e manutenção.

**Tecnologia do aplicativo:** Dart + Flutter. **Back-end e banco de dados:** tecnologias ainda a decidir pela equipe.

> O repositório organiza o trabalho. As funcionalidades ainda não estão implementadas.

## O que cada parte do projeto faz?

| Área | Responsabilidade |
| --- | --- |
| **UI/UX (Design)** | Desenha as telas no Figma e planeja como o usuário navega pelo aplicativo. |
| **Front-end (Dart/Flutter)** | Transforma o design em telas, botões, formulários e navegação no celular. |
| **Back-end (API)** | Processa pedidos, aplica regras, valida informações e comunica o app com os dados. |
| **Banco de Dados** | Organiza e armazena usuários, profissionais, serviços, pedidos e avaliações. |
| **Autenticação** | Faz cadastro, login e controla o acesso de clientes e prestadores. |
| **Busca e GPS** | Permite procurar profissionais por categoria e proximidade com consentimento do usuário. |
| **Solicitações** | Gerencia envio, aceite, recusa, andamento e conclusão de serviços. |
| **Avaliações** | Permite avaliar profissionais depois de serviços concluídos. |
| **Testes (QA)** | Verifica erros, segurança, acessibilidade e funcionamento do app. |
| **Documentação/Gestão** | Define o escopo, organiza as tarefas e registra decisões da equipe. |

## Funcionalidades do primeiro MVP

Cadastro e login; perfis de cliente e profissional; categorias e busca; localização com consentimento (com opção manual); solicitações e respostas; histórico dos pedidos; e avaliações após conclusão.

**Ficam para depois:** pagamentos integrados, monetização, rastreamento em tempo real, seguros, verificação avançada e notificações push.
