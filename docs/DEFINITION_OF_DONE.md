# Definition of Done — Critérios de conclusão

Uma issue de implementação só está pronta quando:

- [ ] O comportamento especificado e os critérios de aceite foram atendidos.
- [ ] Há evidência de teste de cenário positivo e de pelo menos um cenário de erro relevante.
- [ ] Código Dart/Flutter formatado com `dart format` e validado com `flutter analyze` (quando o projeto Flutter existir).
- [ ] Testes automatizados adequados incluídos ou justificativa documentada.
- [ ] Sem credenciais, tokens ou dados pessoais reais no commit.
- [ ] Layout e uso acessível revisados quando se tratar de interface.
- [ ] README ou documentação técnica atualizados se necessário.
- [ ] Pull request revisado por outro integrante quando possível.
- [ ] PR descreve qual issue atende (ex.: `Closes #18`).

Para issues de planejamento/design, substituir a verificação de código por revisão do documento ou protótipo e validação pelo grupo.

**Não concluir** uma issue apenas por existir uma tela visual, sem implementar ou demonstrar seu comportamento, se o critério exigir funcionalidade.
