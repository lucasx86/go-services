# Ordem de desenvolvimento — GO Services!

Este é um plano de execução simples, sem prazos ou responsáveis definidos. A equipe pode atribuir cada issue a um integrante no GitHub.

## 1. Planejar e desenhar
- [#1 Documentação/Gestão](https://github.com/lucasx86/go-services/issues/1): definir o MVP e as regras.
- [#4 UI/UX](https://github.com/lucasx86/go-services/issues/4): criar o fluxo e as telas no Figma.

## 2. Criar a base do aplicativo
- [#5 Front-end](https://github.com/lucasx86/go-services/issues/5): iniciar Flutter/Dart e implementar as telas.
- [#7 Banco de Dados](https://github.com/lucasx86/go-services/issues/7): estruturar as informações.
- [#8 Back-end](https://github.com/lucasx86/go-services/issues/8): criar API e regras de negócio.

## 3. Fazer as funções principais
- [#9 Autenticação](https://github.com/lucasx86/go-services/issues/9): cadastro, login e perfis.
- [#13 Busca/GPS](https://github.com/lucasx86/go-services/issues/13): categorias, filtros e localização.
- [#18 Serviços](https://github.com/lucasx86/go-services/issues/18): enviar, aceitar e acompanhar pedidos.
- [#23 Avaliações](https://github.com/lucasx86/go-services/issues/23): avaliar após serviço concluído.

## 4. Conferir e apresentar
- [#26 Testes](https://github.com/lucasx86/go-services/issues/26): testar o fluxo completo e corrigir problemas.

**Como trabalhar:** atribuam responsáveis às issues; usem as caixas de seleção para acompanhar as entregas; ao concluir, mostrem evidências e fechem a tarefa.

**Futuro, fora do MVP:** pagamentos, planos Premium, notificações push e rastreamento ao vivo.
